AI 손글씨 행맨

프로젝트 소개

사용자가 직접 쓴 알파벳을 AI가 인식하여 단어를 맞히는 행맨 게임입니다. 영어 단어 학습에 손글씨 입력을 결합하여, 게임을 즐기며 AI의 이미지 인식 기능을 체험할 수 있도록 제작했습니다.

주요 기능
01손글씨 입력 · 화면의 캔버스에 마우스나 터치로 알파벳 한 글자를 작성합니다.
02AI 문자 인식 · 제출한 손글씨를 EMNIST 기반 모델로 분석하여 게임에 사용할 문자를 추출합니다.
03단어 맞히기 · 힌트를 참고하여 알파벳을 제출하고, 맞힌 글자를 화면에서 확인합니다.
04진행 상황 표시 · 오답 횟수에 따라 행맨 이미지가 단계적으로 변경되며, 제한 횟수에 도달하면 게임이 종료됩니다.
05새 게임 시작 · 게임 종료 후 재시작 버튼을 누르면 현재 난이도의 단어 중 하나를 무작위로 선택하고 진행 상태를 초기화합니다.
AI 인식 과정

캔버스 이미지를 흑백으로 변환하고, 전처리 함수를 거쳐 28×28 크기의 모델 입력으로 구성합니다.
모델이 출력한 예측 확률 중 가장 높은 값이 70% 이상인 경우에만 인식 결과를 사용하며, 조건을 충족하지 못하면 다시 작성하도록 안내합니다. 숫자 0과 5의 인식률이 매우 낮아 각각 알파벳 o와 s로 보정하여 게임 입력에 활용합니다.

사용 기술

Python, Streamlit, streamlit-drawable-canvas, NumPy, Pillow, EMNIST 기반 손글씨 인식 모델

구현 포인트

손글씨 입력, 이미지 전처리, AI 추론, 게임 판정, 화면 갱신을 하나의 흐름으로 연결했습니다. Streamlit의 세션 상태를 활용하여 화면이 재실행되어도 현재 문제, 맞힌 글자, 오답 횟수와 게임 종료 여부가 유지되도록 구현했습니다.
